# Constitution

1. Every decision, project and strategy is a hypothesis. — enforced by: ledger switches
2. With us, telling the truth is safe. — enforced by: bad-news routing
3. We name the assumptions we are counting on and monitor them continuously. — enforced by: assumption cycle
4. We commit with confidence and monitor relentlessly. — enforced by: decision switches
5. We analyse and document the reversibility of our decisions. — enforced by: decision classes
6. We take responsibility for the outcomes the system produces. — enforced by: accountable field
7. We treat the system as a colleague, not an authority. — enforced by: legible reasoning, overrides
